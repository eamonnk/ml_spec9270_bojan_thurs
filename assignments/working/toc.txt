### 3.12 — Build Pipeline and Train 5 Models

We train five classification models, selected to cover a range of different algorithmic approaches:

- **Logistic Regression** — a linear model, simple and interpretable baseline. Sensitive to feature scaling and skewness, which we have addressed in preprocessing.
- **Random Forest** — an ensemble of decision trees using bagging. Robust to outliers and skewness, handles class imbalance well with `class_weight='balanced'`.
- **Gradient Boosting** — a boosting ensemble that builds trees sequentially, each correcting errors of the previous. Generally strong performance on tabular data.
- **K-Nearest Neighbours (KNN)** — a distance-based model. Sensitive to feature scaling which is handled by RobustScaler in the pipeline.
- **Naive Bayes (Gaussian)** — a probabilistic model based on Bayes theorem, assumes features are normally distributed and independent. Fast and simple, useful as a baseline comparison.

All models are wrapped in a sklearn `Pipeline` with the preprocessor, ensuring that `RobustScaler` and `OneHotEncoder` are fitted on `X_train` only and applied to `X_test` and the query set without refitting — preventing data leakage.

Given the class imbalance (88% TypeA / 12% TypeB), `class_weight='balanced'` is applied where supported. We use **ROC-AUC** as the primary evaluation metric as it is more informative than accuracy for imbalanced datasets.
