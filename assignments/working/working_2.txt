==== PCA reasoning ====
PCA was considered as a possible dimensionality reduction method. However, it was not selected for the final model because the dataset did not have extremely high dimensionality after preprocessing, and many of the variables had clear business meaning. Applying PCA would reduce interpretability by replacing original variables with abstract components. Since the objective was not only predictive accuracy but also understanding which customer characteristics contributed to TypeB predictions, the original engineered and encoded feature set was retained.

=== INformation gain and Gini =====

nformation gain was considered as a feature selection concept. However, manual calculation was not required because tree-based models such as Random Forest and Gradient Boosting automatically select useful splits during training using impurity-based criteria. In sklearn, Random Forest uses Gini impurity by default, while entropy can be selected as an alternative criterion. Therefore, feature relevance was assessed through model performance and feature importance rather than manually computing information gain.


====== backward forward SFS ==============

"Sequential feature selection with full range exploration (forward k=10, backward k=1) identified age, balance and housing as the most robustly informative numerical features, selected by both search strategies.

When rerun with optimal k values identified from the performance plots (forward k=3, backward k=4), only default appeared in the overlap. This is notable as default scored zero in mutual information analysis (I-Gain=0.000), suggesting it provides combinatorial value within small feature subsets despite carrying no independent predictive signal.

This finding illustrates a key advantage of wrapper methods over filter methods — they can identify features that are useful in combination even when individually uninformative."

==== chi squareed and cramer V ======

"Filter-based feature selection was applied separately 
to numerical and categorical features using appropriate 
statistical measures for each feature type.

Numerical features were assessed using Mutual Information 
(I-Gain), which measures non-linear statistical dependence 
between each feature and the target variable. pdays 
(I-Gain=0.023) and balance (I-Gain=0.020) were identified 
as the strongest numerical predictors. The engineered 
feature contacted_previously (I-Gain=0.009) demonstrated 
meaningful predictive signal, validating the feature 
engineering decision. default scored zero (I-Gain=0.000) 
confirming its heavily imbalanced distribution (1.8% yes) 
carries no independent predictive signal.

Categorical features were assessed using chi-square testing 
for statistical significance and Cramers V for association 
strength. Chi-square confirmed all categorical features as 
statistically significant at p<0.05 except job (p=0.241). 
However chi-square scores are sensitive to sample size — 
contact scored chi2=796.67 due to large volume differences 
between cellular (64.7%) and telephone (6.4%) categories, 
artificially inflating its ranking.

Cramers V, which normalises chi-square by sample size, 
provides a more reliable association ranking. poutcome 
(V=0.319) was correctly identified as the strongest 
categorical predictor, consistent with EDA findings 
showing 66.78% TypeB conversion for previously successful 
customers. month (V=0.268) ranked second confirming strong 
seasonal signal. contact dropped to third (V=0.155) 
reflecting genuine but less dominant association.

These filter-based results are consistent with EDA 
findings throughout section 2 and validate the 
preprocessing decisions made in steps 3.2-3.8. 
No features were removed as a result of this analysis — 
all features were retained for the main model pipeline."
